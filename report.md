## Вариант задания

Вариант №17 — **недвижимость**. Справочники:
- Клиенты (clients)
- Объекты недвижимости (objects)
- Специалисты (specialists)

Связующая таблица `appointments` (записи на просмотр / встречи) для проверки целостности при удалении.

## Структура базы данных

Были созданы следующие таблицы (MySQL 8.0):

```sql
clients: id, first_name, last_name, phone, email, birth_date
objects: id, address, type, area, price, description
specialists: id, first_name, last_name, phone, email, specialization
appointments: id, client_id, object_id, specialist_id, date_time, status
```

Внешние ключи с ограничением `ON DELETE RESTRICT` для предотвращения удаления связанных записей.

## Архитектура приложения

Приложение построено по упрощённому шаблону MVC без использования фреймворков:
- **Модель** — классы-репозитории (`ClientRepository`, `ObjectRepository`, `SpecialistRepository`), реализующие доступ к данным через PDO.
- **Контроллеры** — `ClientController`, `ObjectController`, `SpecialistController`; обрабатывают запросы, вызывают методы репозиториев и передают данные в представления.
- **Представления** — PHP-файлы с HTML-разметкой и минимальными вставками PHP для вывода данных.
- **Маршрутизация** — через параметр `entity` и `action` в URL (например, `?entity=client&action=list`).

Все SQL-запросы вынесены в репозитории, представления не содержат прямых обращений к базе данных.

## Реализованный функционал

1. **CRUD-операции** для трёх справочников:
   - Создание записи (create.php с формой).
   - Редактирование (edit.php с предзаполненной формой).
   - Удаление с подтверждением (delete.php) и проверкой связанных записей в `appointments`.
   - Список записей (list.php) с пагинацией (10 записей на странице).

2. **Сортировка и поиск:**
   - Сортировка по любому столбцу таблицы (кликабельные заголовки).
   - Поиск по текстовым полям (имя, телефон, адрес, тип и т.д.) с сохранением параметров при пагинации.
   - Для справочника «Объекты» реализована сортировка по цене (возрастание/убывание).

3. **Валидация данных:**
   - Обязательная серверная проверка (пустые поля, формат телефона, email, дата рождения не в будущем и возраст ≥ 18 лет для клиентов, положительная цена, числовая площадь).
   - Клиентская валидация через атрибуты HTML5 (`required`, `type`, `pattern`) и JavaScript-подтверждение удаления.
   - При ошибках форма перерисовывается с подсветкой неверных полей и сообщениями.

4. **Безопасность:**
   - Экранирование вывода через `htmlspecialchars()`.
   - CSRF-защита: токен генерируется в сессии, добавляется в формы и проверяется при POST-запросах.
   - Проверка ID на положительное целое число.

5. **Flash-сообщения:**
   - После операций создания/обновления/удаления происходит редирект на список с отображением сообщения об успехе или ошибке (хранятся в сессии).

6. **Стилизация и адаптивный дизайн:**
   - Единый CSS в файле `layout.php` (современный стиль с тенями, скруглениями, акцентными цветами).
   - Адаптивная вёрстка для мобильных устройств (таблицы превращаются в карточки с `data-label`).
   - Кнопки, поля форм, flash-сообщения стилизованы для лучшей читаемости.

   - Реализована дополнительная страница «Просмотр деталей записи» (`view.php`) со списком связанных записей.

## Ключевые технические решения

- Использование **автозагрузки классов** через `spl_autoload_register`.
- Применение **подготовленных выражений PDO** для всех SQL-запросов.
- Работа с сессиями для flash-сообщений и CSRF-токенов.
- Строгая проверка входных параметров (`ctype_digit` для ID, белые списки для полей сортировки).
